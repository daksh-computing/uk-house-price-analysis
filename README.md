# UK House Price Analysis: Big Data Analytics

Final-year project for the **Big Data** module of my BSc (Hons) Computing Science at Coventry University (CU London).

An analysis of six years of **HM Land Registry** house price data (around **12 million rows across 15 columns**) for a mortgage-lender scenario, looking at house price trends and using machine learning to model prices.

## What I did

- **Database design:** designed the database and loaded, cleaned and queried the full dataset in **MySQL**.
- **Processing at scale:** processed the data with **Apache Spark**.
- **Machine learning:** applied machine learning to model house prices.
- **Dashboard:** built a **Flask** dashboard to visualise trends and findings for non-technical users.
- **Reporting:** presented the methods and results in a written report and a presentation.

## Tech used

- MySQL / SQL
- Apache Spark
- Python and machine learning
- Flask

## Data

HM Land Registry Price Paid Data (UK government open data).
